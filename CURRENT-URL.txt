URL RESMI UNIVMEET (PERMANEN)
=============================

    https://univmeet.pages.dev

    Link rapat:  https://univmeet.pages.dev/r/<kode-rapat>

STATUS
------
- Gratis, tanpa kartu kredit.
- PC boleh dimatikan — server jalan di Cloudflare.
- Tidak ada halaman peringatan (beda dengan ngrok).
- HTTPS otomatis (wajib untuk kamera/mikrofon).
- Sudah dites end-to-end: video 2 arah, suara, chat, kunci rapat,
  kick, dan promosi host otomatis — 12/12 lolos di URL live.

ARSITEKTUR
----------
  Browser  <--WSS-->  Cloudflare Pages (univmeet.pages.dev)
                          |
                          +--> Durable Object "RoomDO" (per kode rapat)
                               menyimpan daftar peserta + relay sinyal WebRTC

  Video/audio TIDAK lewat server (P2P langsung antar browser).
  Server hanya mengatur "siapa bertemu siapa" (signaling).

CARA UPDATE KALAU KODE DIUBAH
-----------------------------
  cd "C:\Users\DIZZO KINTIL\hermes project\web\univmeet"

  # kalau worker/DO berubah:
  npx wrangler deploy --config wrangler.worker.jsonc

  # kalau tampilan/logika frontend berubah:
  npx wrangler pages deploy --project-name univmeet --branch main --commit-dirty=true

CATATAN TEKNIS
--------------
- `wrangler.jsonc`          = konfigurasi Pages (production branch: main)
- `wrangler.worker.jsonc`   = konfigurasi Worker (Durable Object RoomDO)
- Pages Functions: functions/ws.js (WebSocket), functions/config.js, functions/healthz.js
- Logika protokol dipakai bersama: lib/protocol.js

- workers.dev DIBLOKIR ISP Indonesia (DNS NXDOMAIN + TLS reset),
  makanya dipakai pages.dev. Jangan pindah ke *.workers.dev.

JALAN LOKAL (buat ngoprek)
--------------------------
  npm install
  npm start           -> http://localhost:3000

  Dobel-klik NYALAIN-UNIVMEET.bat kalau mau lokal + tunnel sementara.
