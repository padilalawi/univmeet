CARA NYALAIN
------------
Dobel-klik: NYALAIN-UNIVMEET.bat   (di folder ini)

Syarat: PC nyala + internet. Jendela tunnel jangan ditutup.

MANUAL
------
  npm start
  env -u ALL_PROXY -u HTTPS_PROXY -u HTTP_PROXY ~/tools/ngrok.exe http 3000

CATATAN PENTING
---------------
- ngrok butuh koneksi langsung (JANGAN lewat Tor) — kalau lewat proxy, ngrok
  menolak: "Invalid configuration property value for 'proxy'".
- Token ngrok tersimpan di: %LOCALAPPDATA%\ngrok\ngrok.yml
- Token pernah ditempel di chat -> sebaiknya di-rotate:
  dashboard.ngrok.com/get-started/your-authtoken -> Revoke -> buat baru.
